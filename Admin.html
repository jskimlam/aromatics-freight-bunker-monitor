📤 F/B LAM 관리자

데일리 원본 HTML을 Google Sheet에 백업한 뒤 GitHub Pages 대시보드에 자동 발행합니다.

1. 관리자 인증

먼저 관리자 비밀번호를 입력하세요.

2. GitHub 연결

GitHub Token은 화면에 다시 표시하지 않으며 Apps Script의 GITHUB_TOKEN 속성에만 저장합니다.
대상 저장소: jskimlam/aromatics-freight-bunker-monitor@main
관리자 인증 후 GitHub Token 상태를 확인합니다.

3. HTML 업로드

파일명 규칙
데일리: freight_YYYYMMDD.html
예: freight_20260928.html
대시보드 화면·차트·인쇄 설정을 자유롭게 변경할 수 있습니다. 업로드한 원본 HTML은 임의로 가공하지 않고 그대로 보존합니다.
